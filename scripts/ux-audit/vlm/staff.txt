The two cards do not feel like true siblings in the grid.

While semantically distinct, the visual treatment (border presence vs. absence, exact background tint) should be standardized to a single badge component variant system to avoid looking like different components.
- **[SEVERITY: minor]** **Missing status indicators on right card items.** The "Planning Room" and "Field Updates" list items in the right card lack any status metadata or badges, creating an information hierarchy mismatch compared to the left card which shows ONGOING/COMPLETED states. This breaks the expectation that sibling cards in a dashboard grid present data at similar granularity.

**PAGE: My Profile (Image 2)**

- **[SEVERITY: critical]** **Misaligned primary action button.** The "Save profile" button is floated to the far right edge of the form area, disconnected from the form fields above it. It sits in isolation rather than being anchored to the end of the form flow (e.g., below the Location field or centered), breaking the vertical reading rhythm and F-pattern eye movement.
- **[SEVERITY: moderate]** **Orphaned whitespace in Details card.** Between the Photo upload section and the Full name/Location fields, there is excessive vertical whitespace that creates a visual "hole." The form feels split into two unconnected zones rather than one cohesive editing surface.
- **[SEVERITY: moderate]** **Workspace cards have inconsistent text density.** In the "Your workspace" 2×2 grid, the four cards ("Chat rooms," "Campaign teams," "Profile & photo," "Verified organisation") contain varying line counts of description text (2–3 lines). This causes the cards to have uneven heights, breaking the grid's horizontal alignment baselines. These should either have fixed heights or use flexbox alignment to equalize.
- **[SEVERITY: minor]** **Button style mismatch.** The "Save profile" button is solid green (filled), while the "Change image" and "Remove" buttons are ghost/text variants. While this may be intentional for primary vs. secondary actions, the "Remove" button (destructive action) uses the same neutral styling as "Change image" (neutral action), which is a subtle semantic color-language inconsistency.
- **[SEVERITY: minor]** **Avatar size inconsistency.** The circular avatar in the user identity card (top) appears slightly larger than the square avatar in the Photo upload section below. For a profile page, these should likely share the same dimensions or follow a clear size scale (e.g., 64px vs. 80px) that looks intentional rather than accidental.

- **[SEVERITY: critical]** **Broken message alignment rhythm.** The outgoing message ("Confirmed. I will pick up...") is right-aligned as expected, but its vertical positioning creates an awkward gap with the message above it (from Bright Futures Trust). Meanwhile, incoming messages are left-aligned but their timestamps hang at inconsistent vertical positions relative to their bubbles. The chat lacks a strict baseline grid for message spacing.
- **[SEVERITY: moderate]** **Avatar vertical misalignment.** The circular avatars (BT, PS, RP) are not perfectly center-aligned with their respective message bubble start points. Some avatars appear to sit slightly higher or lower relative to the first line of text in their adjacent bubble, creating a jittery vertical rhythm down the thread.
- **[SEVERITY: moderate]** **Input area composition imbalance.** The text input field ("Write a message...") takes up ~85% of the width while the send button (paper plane icon) is a small square button on the right. The disproportionate sizing makes the input area look like it's missing a companion element (e.g., attachment button) to balance the composition, or the send button should be larger/inline to match the input height better.
- **[SEVERITY: minor]** **Timestamp color contrast risk.** The timestamps (12:00, 09:00, etc.) are rendered in a very light grey that may fail WCAG AA contrast requirements against the white background. While aesthetically "clean," this risks readability issues for users with low vision.
- **[SEVERITY: minor]** **Inconsistent message bubble padding.** The outgoing green bubble appears to have different horizontal padding (tighter) compared to the incoming grey bubbles (more generous), making the two sides of the conversation feel like they're using different components rather than a single MessageBubble component with variant props.
- **[SEVERITY: minor]** **Help text orphaned below input.** The "Enter to send · Shift+Enter for a new line" hint text is very small and loosely associated with the input field. It sits in a typographic no-man's-land between the input border and the card container edge, lacking clear visual grouping with its parent input.

**SUMMARY OF CROSS-PAGE SYSTEMIC ISSUES:**

1. **Card Height Synchronization:** Across all three pages, cards in the same row/grid do not enforce equal heights (Image 1 bottom row, Image 2 workspace grid), causing ragged bottom edges.
2. **Status Badge Taxonomy:** The platform uses at least three visual dialects for status pills (green-filled, green-outlined, grey-filled) without a clear, consistent legend visible across contexts.
3. **Action Button Placement:** Primary actions float to edges (Image 2 Save button) or vary in treatment (Image 3 send button), lacking a consistent pattern for where users expect to find "commit" actions.
4. **Typography Scale Drift:** Muted/help text sizes appear to vary between the dashboard subtitles, form hints, and chat timestamps, suggesting the design token for `text-muted` or `text-xs` is not strictly enforced.
