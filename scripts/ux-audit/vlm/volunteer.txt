**Image 8**
**PAGE:** Volunteer Dashboard (Aisha Khan - New User State)

**ISSUES:**

1.  **[SEVERITY: critical]** **Location: Top stat row (third card - Rating).** The value displayed is "New" (text) instead of a number. Sibling cards show "0", "0", and "1". Displaying a string ("New") in a slot designed for metrics (numbers) breaks the data visualization pattern. It should likely show "—" (em-dash) or "0.00" to maintain the numeric rhythm, with "New" perhaps as subtext.
2.  **[SEVERITY: moderate]** **Location: "My campaigns" card (Empty State).** This card uses a centered layout with a heart icon, text, and a CTA button ("Find a campaign"). This is a "call-to-action" empty state.
3.  **[SEVERITY: moderate]** **Location: "My chat rooms" & "Funds allocated to me" cards (Empty States).** These cards use a different empty state pattern: icon + bold title + description text. They *lack* a primary action button inside them.
    *   **Why it breaks rhythm:** You have two different empty state metaphors on the same page (CTA vs Informational). The "My campaigns" card looks like a landing spot, while the others look like disabled sections. This inconsistency confounds the user's mental model of "what can I do here?".
4.  **[SEVERITY: minor]** **Location: Invitation banner.** The green banner ("You have 1 campaign invitation") spans the full width of the grid. Inside it, the "Winter Shelter Support" pill and "PENDING" badge are grouped. The "Review invitations" button is far to the right. The banner's background color is lighter than the primary buttons but darker than the page background. It fits well, but the transition from the white stat cards above to this light-green banner and back to white cards below creates a "sandwich" effect that stops the eye slightly.

**VERDICT:** Good handling of empty states overall, but the **inconsistency between empty state patterns (Issue 3)** and the **data type mismatch in stats (Issue 1)** need fixing before ship.
